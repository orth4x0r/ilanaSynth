- **Old presets must not change.** Check with `ilanaFingerprint` before and after, then `python tools/compare_fingerprints.py before.csv after.csv`. `build/fingerprints-m7.5.csv` is the current Windows baseline (256 presets; the first 250 match `build/fingerprints-m7.2.csv`); on Linux, `tests/fingerprints-linux.csv` (committed; `tools/verify.sh` compares against it) (with a row per filter model; Live Body and Live Wah always differ run to run) (`build/fingerprints-v1.2.csv` is v1.2's). New presets are appended at the end of the list. Against v1.2, 26 reverb presets differ at the tool's 48 kHz only, because the reverb now gets the real sample rate. At 44.1 kHz they are unchanged. Two more (Through-Zero Growl, Shift Bass) differ only because voice random state carries over between presets within the run. The release polish changed fingerprints on purpose, each explained in ROADMAP: debug 1 (38: continuous knobs; a patch load resets tails and modulators, so fingerprints no longer depend on the preset before), debug 2 (21: voice state cleared on load), debug 5 (14 strings: tuning fix).
