## Rules that still apply
- The PLAY strip layout and the arranger layouts are ilana's own designs: polish, never undo. UI reviews score against Vital and Serum 2; no unused space is the top priority.
- **Old presets must not change.** Check with `ilanaFingerprint` before and after, then `python3 tools/compare_fingerprints.py before.csv after.csv`. The only baseline is `tests/fingerprints-linux.csv` (committed; `tools/verify.sh` compares against it; a row per filter model; Live Body and Live Wah always differ run to run, everything else is identical run to run). New presets are appended at the end of the list. The release polish changed fingerprints on purpose, each explained in ROADMAP: debug 1 (38: continuous knobs; a patch load resets tails and modulators), debug 2 (21: voice state cleared on load), debug 5 (14 strings: tuning fix); the Linux baseline was updated for them. Windows has no fingerprint baseline: use the Linux one plus the Windows syntax check below.
- **Parameter IDs and choice indices are never renumbered.** New choices, destinations and sources are appended.

- **Randomness:** new features get their own random generators (as `lfoPoolRandom` and the FM noise operator's `fmNoiseRandom` do), so existing presets' random sequences don't shift. Physical string banks have explicit seeds for the same reason.

- **UI work: ilana's aesthetic checklist (2026-10-19: "apply them to all redesigns and ui work before telling me its Done").** Self-check every picture against it and report each as pass or fail before showing it: matches the mock element by element (sizes, positions, wording, graphics; "can't fit" and "existing style" are not reasons); no dead space, empty tails, empty cells or half-empty sections; even knob gaps and even left/right margins; labels share one left edge and toggles sit in one column; controls centred in their section; no clipped labels; values keep about 3 px clearance from rings and are one size (no shrink-to-fit); no stretched menus; pictures and graphs big and readable; nothing smaller than in the mock.
